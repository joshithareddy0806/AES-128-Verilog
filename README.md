# 🔐 AES-128 Encryption and Decryption using Verilog HDL

## 📖 Overview

This project implements the Advanced Encryption Standard (AES-128) algorithm using Verilog HDL. The design supports both encryption and decryption operations through a modular RTL architecture, making it suitable for FPGA implementation and digital hardware applications.

The project was developed and verified using Xilinx Vivado with functional simulations to validate the correctness of the AES algorithm.

---

## ✨ Features

- AES-128 Encryption
- Modular RTL Design
- Key Expansion
- Round Transformations
- FPGA Compatible
- Functional Simulation using Vivado

---

## 🛠️ Tools Used

- Verilog HDL
- Xilinx Vivado
- Basys-3 FPGA (Compatible)
